E-Coffee Tray Utility - High Contrast Icons
===========================================

English
-------
How to start
1. Extract every file from the ZIP archive to a permanent folder.
2. Double-click "Start E-Coffee.cmd".
3. E-Coffee runs in the Windows notification area without a console or PowerShell window.

Tray controls
- Steaming coffee cup: Keep Awake is enabled.
- Empty coffee cup: Keep Awake is disabled.
- Double-click the tray icon to toggle Keep Awake.
- Right-click the tray icon for status, toggle, startup, and exit options.

Automatic startup
- Right-click the tray icon.
- Select "Start automatically when I sign in".
- Select it again to disable automatic startup.
- Keep the E-Coffee folder in the same location after enabling startup.

Notes
- E-Coffee starts with Keep Awake enabled.
- No administrator privileges or installation are required.
- It does not modify the registry or power plan.
- It does not bypass organization-enforced lock or security policies.
- Press Win+L whenever you step away from your computer.

Français
--------
Comment démarrer
1. Extrayez tous les fichiers de l'archive ZIP dans un dossier permanent.
2. Double-cliquez sur "Start E-Coffee.cmd".
3. E-Coffee s'exécute dans la zone de notification Windows sans fenêtre de console ni PowerShell.

Contrôles de la zone de notification
- Tasse de café fumante : Veille activée.
- Tasse de café vide : Veille désactivée.
- Double-cliquez sur l'icône pour activer/désactiver la veille.
- Cliquez avec le bouton droit pour le statut, la bascule, le démarrage et les options de sortie.

Démarrage automatique
- Cliquez avec le bouton droit sur l'icône.
- Sélectionnez "Start automatically when I sign in".
- Sélectionnez à nouveau pour désactiver le démarrage automatique.
- Conservez le dossier E-Coffee au même emplacement après avoir activé le démarrage.

Remarques
- E-Coffee démarre avec la veille activée.
- Aucun privilège d'administrateur ou installation n'est requis.
- Ne modifie pas le registre ni le plan d'alimentation.
- Ne contourne pas les verrous ou politiques de sécurité imposés par l'organisation.
- Appuyez sur Win+L chaque fois que vous vous éloignez de votre ordinateur.

中文
----
如何启动
1. 将 ZIP 压缩包中的所有文件解压到固定文件夹。
2. 双击 "Start E-Coffee.cmd"。
3. E-Coffee 将在 Windows 通知区域运行，不显示控制台或 PowerShell 窗口。

托盘控制
- 冒热气的咖啡杯：已启用保持唤醒。
- 空咖啡杯：已禁用保持唤醒。
- 双击托盘图标可切换保持唤醒状态。
- 右键单击托盘图标可查看状态、切换、启动和退出选项。

自动启动
- 右键单击托盘图标。
- 选择 "Start automatically when I sign in"（登录时自动启动）。
- 再次选择可禁用自动启动。
- 启用自动启动后，请保持 E-Coffee 文件夹位置不变。

注意事项
- E-Coffee 启动时默认启用保持唤醒。
- 无需管理员权限或安装。
- 不修改注册表或电源计划。
- 无法绕过组织强制的锁定或安全策略。
- 离开电脑时请按 Win+L 锁定屏幕。
